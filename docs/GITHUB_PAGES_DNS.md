# GitHub Pages (optional mirror)

Прод-сайт хостится на **reg.ru**: см. [REG_RU_HOSTING.md](./REG_RU_HOSTING.md).

Workflow `Deploy to GitHub Pages` может публиковать зеркало на
`https://masterofowls.github.io/cubichi/`. Кастомный домен `cubichi.ru`
на GitHub Pages **не** использовать — DNS указывает на хостинг reg.ru
(`31.31.197.15` / `2a00:f940:2:2:1:1:0:279`).
